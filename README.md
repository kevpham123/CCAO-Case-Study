# CCAO Case Study

## Overview
This project is inspired by "An Unfair Burden: Cook County failed to value homes accurately for years. The result: a property tax system that harmed the poor and helped the rich." This project will delve deeper into the findings in the article to understand how this problem occurred and find possible solutions for it. This is the [link](https://apps.chicagotribune.com/news/watchdog/cook-county-property-tax-divide/assessments.html) to the article which this project is based on. 


## Repository Structure

The project is split between two Interactive Python Notebook. Project A1 contains code used during the EDA/data cleaning process while A2 contains code for the linear regression model I made to predict property values. These prediction will be used to observe how the CCAO overvalued lower income property.

.
├── README.md           # Project documentation
